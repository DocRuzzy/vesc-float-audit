# Examples

Synthetic bundles built by `tools/make_examples.py` from upstream defaults and example tunes. **They are not captures from the owner's boards** and nothing in them has been validated on hardware.

- `synthetic-board-a/`: Thor 301, 20S2P, with Refloat's default HV pushback (4.3 V/cell = 86 V)
- `synthetic-board-b/`: Ubox Single 100V, 15S1P, with a 5-sample synthetic Float Control log
- `reports/`: the audit of each bundle and their comparison
